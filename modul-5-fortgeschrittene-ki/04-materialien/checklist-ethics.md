# Ethics Checklist

Checkliste für ethischen AI-Einsatz.

## Vor der Entwicklung

- [ ] Zweck klar definiert
- [ ] Stakeholder identifiziert
- [ ] Risiken analysiert
- [ ] Alternativen geprüft

## Bias & Fairness

- [ ] Training-Daten auf Bias geprüft
- [ ] Diverse Test-Cases
- [ ] Fairness-Metriken definiert
- [ ] Regelmässige Audits geplant

## Datenschutz

- [ ] DSGVO-Compliance
- [ ] Daten-Minimierung
- [ ] Anonymisierung wo möglich
- [ ] Sichere Speicherung

## Transparenz

- [ ] AI-Nutzung offengelegt
- [ ] Erklärbarkeit gewährleistet
- [ ] Quellen nachvollziehbar
- [ ] Limitationen kommuniziert

## Verantwortung

- [ ] Verantwortlichkeiten klar
- [ ] Fehlerkorrektur-Prozess
- [ ] Beschwerde-Mechanismus
- [ ] Regelmässige Reviews

## Sicherheit

- [ ] Missbrauch-Prävention
- [ ] Rate Limiting
- [ ] Content Filtering
- [ ] Monitoring
