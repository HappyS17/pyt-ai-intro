# Python & KI-gestütztes Programmieren

Ein innovativer Kurs, der Python-Programmierung mit modernen KI-Tools verbindet und Lernende befähigt, eigenständig professionelle Software-Anwendungen zu entwickeln.

## Kursphilosophie

**Warum noch mühsam Syntax lernen, wenn KI-Tools das Programmieren revolutioniert haben?**

Python bleibt die wichtigste Programmiersprache unserer Zeit - aber die Art, wie wir programmieren, hat sich grundlegend gewandelt. Statt monatelang Syntaxregeln zu büffeln, lernen Sie in diesem innovativen Kurs, wie Sie mit KI-Tools wie GitHub Copilot, ChatGPT und Claude als Ihr digitaler Programmierpartner arbeiten. Sie verstehen die wesentlichen Konzepte und werden schnell zu einem produktiven Entwickler, der komplexe Anwendungen mit KI-Unterstützung erstellt.

**Warum dieser Ansatz die Zukunft ist:** Professionelle Entwickler nutzen bereits heute KI-Tools für 40-60% ihrer Programmierarbeit. Sie lernen von Anfang an die Arbeitsweise der Zukunft.

## Kursziele

Nach Abschluss des Kurses können Sie:

- Fundamentale Programmierkonzepte verstehen und gezielt einsetzen
- Souverän mit KI-Coding-Tools arbeiten und deren Stärken optimal nutzen
- Eigenständig funktionsfähige Python-Anwendungen mit KI-Unterstützung entwickeln
- KI-generierten Code bewerten, anpassen und debuggen
- Moderne Entwicklungsworkflows mit integrierten KI-Tools beherrschen
- Vollständige Web-Anwendungen von der Konzeption bis zum Deployment erstellen

## Installation & Setup

### Vorbereitung für Modul 1

Installieren Sie vor dem ersten Kurstag:

1. **Python**
   - Download: [python.org](https://python.org)
   - Version: 3.11 oder höher
   - Systemvariablen korrekt setzen

2. **Git**
   - Download: [git-scm.com](https://git-scm.com)
   - Grundkonfiguration durchführen

3. **VS Code**
   - Download: [code.visualstudio.com](https://code.visualstudio.com)
   - Extensions: Python, Pylance

4. **uv**

   ```bash
   # macOS/Linux:
   curl -LsSf https://astral.sh/uv/install.sh | sh

   # Windows:
   powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

5. **GitHub Copilot** (empfohlen)
   - Installation in VS Code
   - Oder kostenlose Alternativen

Eine detaillierte Installationsanleitung wird vor Kursbeginn bereitgestellt.
