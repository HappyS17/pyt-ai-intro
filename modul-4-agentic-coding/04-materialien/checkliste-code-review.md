# Code Review Checkliste

Systematische Checkliste für Code Reviews mit KI.

## Funktionalität

- [ ] Code erfüllt Anforderungen
- [ ] Edge Cases behandelt
- [ ] Fehlerbehandlung vorhanden
- [ ] Tests vorhanden und bestehen

## Code-Qualität

- [ ] Aussagekräftige Namen
- [ ] Funktionen sind klein und fokussiert
- [ ] Keine Code-Duplikation
- [ ] SOLID Principles befolgt
- [ ] Type Hints vorhanden
- [ ] Docstrings vorhanden

## Performance

- [ ] Keine offensichtlichen Performance-Probleme
- [ ] Effiziente Algorithmen
- [ ] Keine unnötigen Berechnungen
- [ ] Ressourcen werden freigegeben

## Security

- [ ] Input-Validierung
- [ ] Keine SQL-Injection-Risiken
- [ ] Keine Hardcoded Secrets
- [ ] Sichere Defaults

## Dokumentation

- [ ] README aktualisiert
- [ ] API dokumentiert
- [ ] Komplexe Logik erklärt
- [ ] CHANGELOG aktualisiert
